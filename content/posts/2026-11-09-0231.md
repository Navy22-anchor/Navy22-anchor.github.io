이제 성능지표 $F(\mathbf{x})$를 최소화하는 $\mathbf{x}$를 찾아보자. 

- $\mathbf{x_{k}}=\begin{bmatrix}w_{k}\\b_{k}\end{bmatrix}$ 
- $\Delta \mathbf{x_{k}}=\alpha \mathbf{p_{k}}$

## 경사하강법

$F(\mathbf{x_{k+1}})=\mathbf{x_{k}}+\alpha \mathbf{p_{k}}=\mathbf{x_{k}}+\Delta \mathbf{x_{k}}$  로 정의해보자.

이때 우리가 찾는 것은 다음 조건을 만족해야한다.

$$
F(\mathbf{x_{k+1}})<F(\mathbf{x_{k}}) \tag{1}$$

[테일러 급수](https://velog.io/@navy22-anchor/%EC%84%B1%EB%8A%A5-%ED%91%9C%EB%A9%B4%EA%B3%BC-%EC%B5%9C%EC%A0%81%EC%A0%90)로 $F(\mathbf{x_{k+1}})$를 표현해보자.

$F(\mathbf{x_{k+1}})=F(\mathbf{x_{k}}+\Delta \mathbf{x_{k}}) \approx F(\mathbf{x_{k}})+\mathbf{g_{k}^T}\Delta \mathbf{x_{k}}$

- $\mathbf{g_{k}^T}=\nabla F$

조건 (1)에 의해 

$$
\mathbf{g_{k}^T}\Delta \mathbf{x_{k}} < 0 \longrightarrow \mathbf{g_{k}^T}(\alpha \mathbf{p_{k}}) < 0 \longrightarrow \mathbf{g_{k}^T}( \mathbf{p_{k}}) < 0 \tag{2}
$$

따라서 조건 (2)를 만족한다면 $F(\mathbf{x_{k+1}})$는 작아지게된다. 이때 가장 빠르게 작아지려면 어떻게 해야할까? 이제 조건 (2)를 다시보자. $\mathbf{g_{k}^T}( \mathbf{p_{k}})$은 $\mathbf{g_{k}^T}$와 $( \mathbf{p_{k}})$의 내적이므로 다음과 같다.

$$
\mathbf{g_{k}^T}\cdot( \mathbf{p_{k}})=\|\mathbf{g_{k}^T}\|\|( \mathbf{p_{k}})\|cos(\theta) \tag{3}$$

내적의 값이 빠르게 작아지려면 $cos(\pi)=-1$ 이여야 한다. 따라서 $\mathbf{p_{k}}$는 $\mathbf{g_{k}^T}$의 반대 방향 벡터임을 알 수 있다. 

 $$
\mathbf{p_{k}}=-\mathbf{g_{k}^T}, F(\mathbf{x_{k+1}})=\mathbf{x_{k}}-\alpha \mathbf{g_{k}^T}$$


## 뉴턴법

경사하강법은 $F(\mathbf{x_{k+1}})$을 1차항까지 전개 했다면 뉴턴법은 2차항까지 전개한다.

$F(\mathbf{x_{k}}+\Delta \mathbf{x_{k}}) \approx F(\mathbf{x_{k}})+\mathbf{g_{k}^T}\Delta \mathbf{x_{k}}+\frac{1}{2}\Delta \mathbf{x_{k}}^TA_{k}\Delta \mathbf{x_{k}}$

$\nabla F(\mathbf{x_{k}}+\Delta \mathbf{x_{k}}) \approx \mathbf{g_{k}}+A_{k}\Delta \mathbf{x_{k}}$

이때 [앞의 포스트](https://velog.io/@navy22-anchor/%EC%84%B1%EB%8A%A5-%ED%91%9C%EB%A9%B4%EA%B3%BC-%EC%B5%9C%EC%A0%81%EC%A0%90) 에서 정의했던 1차 조건을 이용한다.

$\nabla F = 0$ , $\Delta \mathbf{x_{k}}=\mathbf{x^*}$(임계점)

$\mathbf{x^*}=-A_{k}^{-1}\mathbf{g}_{k}$

따라서 이 방법은 경사하강법과는 달리 한번의 단계로 끝난다는 점이다. 따라서 학습시간이 매우 짧다.

## 코드 구현

### 1. 경사하강법

0번 수식은 퍼셉트론이며 purelim은 다음 뉴런에 $wp+b$ 값을 그대로 전달한다. 1번 수식은 입력값 $p$와 정답 $t$으로 구성되어 있다. $F$는 성능 지표로 예측값과 정답의 차이를 오차로 정의한다.

$$
a=purelim(wp+b), purelim(x)=x \tag{0}$$

$$
\{(p_1=2),(t_1=0.5)\},\{(p_2=-1),(t_2=0)\} \tag{1}$$

$a_{1}(wp_1+b)+a_{2}(wp_2+b)$를 행렬로 표현하여 작성했다. 

$$
\mathbf{G}=\begin{bmatrix}p_1&1\\p_2&1\end{bmatrix},
\mathbf{x}=\begin{bmatrix}w\\b\end{bmatrix}$$

```python
from sympy import diff, symbols, Matrix
import sympy

def perceptron (p1,p2):
    w=symbols('w')
    b=symbols('b')
    G=Matrix([[p1,1],[p2,1]])
    X=Matrix([[w],[b]])
    return G@X
```

이제 우리는 성능지표를 최소화하는 $\mathbf{x}$를 찾아야한다. 먼저 성능지표 함수를 작성하자. 함수 `mse_loss` 함수의 입력값 $a$는 $\mathbf{G}\mathbf{x}$가 된다.

$$
\begin{aligned}
F(\mathbf{x}) &= (t_{1}-a_{1}(\mathbf{x}))^2+(t_{2}-a_{2}(\mathbf{x}))^2 \\
&= (t_{1}-a_{1}(\begin{bmatrix}p_{1} & 1\end{bmatrix}\begin{bmatrix}w\\b\end{bmatrix}))^2+(t_{2}-a_{2}(\begin{bmatrix}p_{2} & 1\end{bmatrix}\begin{bmatrix}w\\b\end{bmatrix}))^2 \\
&= (\begin{bmatrix}t_{1}\\t_{2}\end{bmatrix}-a(\begin{bmatrix}p_{1} & 1\\p_{2} &1\end{bmatrix}\begin{bmatrix}w\\b\end{bmatrix}))^T(\begin{bmatrix}t_{1}\\t_{2}\end{bmatrix}-a(\begin{bmatrix}p_{1} & 1\\p_{2} & 1\end{bmatrix}\begin{bmatrix}w\\b\end{bmatrix}))\\
&=(\mathbf{t}-a(\mathbf{G}\mathbf{x}))^T(\mathbf{t}-a(\mathbf{G}\mathbf{x}))\\
&=e^Te \tag{2}
\end{aligned}
$$

```python
def mse_loss(t1,t2,a:sympy.Matrix):
    T=Matrix([[t1],[t2]])
    e=T-a
    return (e.T*e)
```
이제 앞서 우리가 알아본 경사하강법 알고리즘을 작성하면된다. 따라서 $\mathbf{g_{k}^T}$를 구하여 $\mathbf{x_{k}}$(가중치)를 입력하고 $\mathbf{x_{k+1}}$를 구하는 과정을 반복하면된다. `starts`,`ends`는 그래프를 그리기 위한 리스트이다.

$$
\mathbf{x_{k+1}}=\mathbf{x_{k}}-\alpha \mathbf{g_{k}^T} \tag{3}$$

```python

def gradient_desent(F,x0:sympy.Matrix,alpha,iter):
    starts = []
    ends = []
    
    for i in F:
        w=symbols('w')
        b=symbols('b')
        F_diff_w=diff(i,w)
        F_diff_b=diff(i,b)
    
    x_old = x0
    
    for _ in range(iter):
        g_k=Matrix([[F_diff_w.subs({w:x_old[0,0],b:x_old[1,0]})],[F_diff_b.subs({w:x_old[0,0],b:x_old[1,0]})]])
        print("g_k: ",g_k)
        x_new = x_old - alpha * g_k
        starts.append(x_old)
        ends.append(x_new)
        x_old = x_new

    return np.array(starts,dtype=float),np.array(ends,dtype=float)
```
*아직 수렴할때 멈추는 것은 개발하지 못 했다. 이 부분을 반복횟수로 대신 설정했다.*

이제 입력값과 초기값을 이 함수에 대입해보자.

$$\mathbf{x0}=\begin{bmatrix}w\\b\end{bmatrix}=\begin{bmatrix}1\\1\end{bmatrix}, \{(p_1=2),(t_1=0.5)\},\{(p_2=-1),(t_2=0)\}$$
